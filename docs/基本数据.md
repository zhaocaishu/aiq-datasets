# 数据依赖

本文列出数据来源和现有脚本需要的输入。导出脚本读取已有的 MySQL `stock_info` 库。Tushare 接口文档核对于 2026-11-11。

## Tushare 数据

`ts_*` 是项目表名。通过下列接口取数时需另行采集。

| 项目表名 | Tushare 接口 / 官方文档 | 用途 |
| --- | --- | --- |
| `ts_basic_stock_list` | [stock_basic](https://tushare.pro/document/2?doc_id=25) | 股票列表、名称、板块、上市状态和日期 |
| `ts_basic_trade_cal` | [trade_cal](https://tushare.pro/document/2?doc_id=26) | 交易日历，导出开市日期 |
| `ts_basic_stock_st` | [stock_st](https://tushare.pro/document/2?doc_id=397) | ST 信息表，记录每个交易日的 ST、\*ST 股票名单（计划接入） |
| `ts_quotation_daily` | [daily](https://tushare.pro/document/2?doc_id=27) | 未复权日线行情 |
| `ts_quotation_daily_basic` | [daily_basic](https://tushare.pro/document/2?doc_id=32) | 换手率、量比、估值、股本、市值 |
| `ts_quotation_adj_factor` | [adj_factor](https://tushare.pro/document/2?doc_id=28) | 复权因子 |
| `ts_quotation_stk_limit` | [stk_limit](https://tushare.pro/document/2?doc_id=183) | 每日涨停价、跌停价 |
| `ts_quotation_moneyflow` | [moneyflow](https://tushare.pro/document/2?doc_id=170) | 分单买卖量与金额，用于计算资金流特征 |
| `ts_quotation_suspend_d` | [suspend_d](https://tushare.pro/document/2?doc_id=214) | 停复牌记录，可导出为 CSV 供缺失检查使用 |

| 功能 | 所需数据 |

## 关联与数据口径

### 股票日线

- 股票列表需包含 `ts_code, name, market, list_status, list_date`。向 `stock_basic` 取数时需在 `fields` 中显式请求 `list_status`。脚本按当前上市状态、板块、股票名称和行业归属筛选股票。
- 行业表按 `ts_code` 关联，使用 `l1_name, l2_name` 生成行业标签。若同一股票有多条行业记录，应先确定用于导出的记录。导入时按 `INDUSTRY_CONS_COLUMN_MAP` 映射字段，行业名称需匹配项目中的枚举编码。
- 行情和辅助表按 `ts_code, trade_date` 内连接，任一辅助表缺失都会使对应交易日的行情被跳过。`moneyflow` 从 2010 年开始，`stk_limit` 从 2007-01-04 开始。
- 脚本按 `daily.*` 的列顺序写入固定表头。`ts_quotation_daily` 的列顺序需为 `ts_code, trade_date, open, close, high, low, pre_close, change, pct_chg, vol, amount`，其中 `trade_date` 需为 `YYYYMMDD` 字符串。
- `daily` 的成交量为手、成交额为千元。`moneyflow` 的成交量为手、金额为万元。`daily_basic` 的股本为万股、市值为万元。分钟数据处理沿用源 CSV 的单位。

### 指数股票池的 ST 信息表

现有脚本根据当日股票名称过滤 ST 股票。成分股缺少同日的历史名称记录时，也会因内连接被过滤。

计划按 `ts_code, trade_date` 查询 `ts_basic_stock_st`，剔除出现在当日 ST 名单中的成分股，保留其余成分股。`stock_st` 的历史数据始于 2000-01-01。使用名单过滤前应核对所需交易日的采集覆盖，避免将采集缺失当作当日无 ST 股票。

### CSV 日期与缺失检查

- 日线和交易日历 CSV 的 `Date` 为 `YYYY-MM-DD`。分钟 CSV 的 `trade_time` 包含日期和时分秒，处理时按日期匹配同一股票的日线复权因子，缺少对应日线日期的分钟记录会被过滤。
- 缺失交易日检查的默认路径和导出目录布局有差异。`suspend_d` 原始日期为 `YYYYMMDD`，当前检查器在转换日期前就按 `YYYY-MM-DD` 筛选，可能漏掉停牌日。检查器将 `suspend_type = 'S'` 的记录用于停牌排除，其中也包含 `suspend_timing` 有值的盘中停牌。

运行命令和当前限制见 [README](../README.md)。

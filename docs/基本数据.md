# 数据依赖

按当前代码及已确认的数据来源整理。`ts_*` 是项目表名；下表给出对应的 Tushare 接口。接口信息核对日期：2026-11-05。

## Tushare 数据

完整流程涉及以下 9 类原始数据。仓库主要从已有 MySQL 数据库导出数据，尚未实现这些接口的自动采集。

| 项目表名 | Tushare 接口 / 官方文档 | 当前用途 |
| --- | --- | --- |
| `ts_basic_stock_list` | [stock_basic](https://tushare.pro/document/2?doc_id=25) | 股票列表、名称、板块、上市状态和日期 |
| `ts_basic_trade_cal` | [trade_cal](https://tushare.pro/document/2?doc_id=26) | 交易日历，导出开市日期 |
| `ts_quotation_daily` | [daily](https://tushare.pro/document/2?doc_id=27) | 未复权日线行情 |
| `ts_quotation_daily_basic` | [daily_basic](https://tushare.pro/document/2?doc_id=32) | 换手率、量比、估值、股本、市值 |
| `ts_quotation_adj_factor` | [adj_factor](https://tushare.pro/document/2?doc_id=28) | 复权因子 |
| `ts_quotation_stk_limit` | [stk_limit](https://tushare.pro/document/2?doc_id=183) | 每日涨停价、跌停价 |
| `ts_quotation_moneyflow` | [moneyflow](https://tushare.pro/document/2?doc_id=170) | 分单买卖量与金额，用于计算资金流特征 |
| `ts_bak_basic` | [bak_basic](https://tushare.pro/document/2?doc_id=262) | 每日股票历史列表，按当日名称过滤 ST 股票 |
| `ts_quotation_suspend_d` | [suspend_d](https://tushare.pro/document/2?doc_id=214) | 停复牌记录，供缺失检查使用；当前检查器读取 CSV |

## 其他来源的数据

| 项目表名 | 来源 | 当前用途 |
| --- | --- | --- |
| `ts_idx_industry_cons` | 外部整理后导入 | 申万行业归属，提供股票行业标签 |
| `ts_idx_index_cons` | 每日成分加工表，仓库包含从成分详情、历史进出记录生成快照的脚本草稿 | 每日指数股票池 |
| `ths_idx_index_daily` | 同花顺 iFind，由抓取脚本获取 CSV 后导入 | 指数行情及成分统计特征 |

行业字段映射和行业、指数表的 DDL 定义见 [common/constants.py](../common/constants.py)，行业类别编码见 [common/industry.py](../common/industry.py)。外部行业表不计入 Tushare 采集清单。

## 按功能准备

| 功能 | 所需数据 |
| --- | --- |
| 股票日线导出 | `ts_basic_stock_list`、`ts_idx_industry_cons`、`ts_quotation_daily`、`ts_quotation_daily_basic`、`ts_quotation_adj_factor`、`ts_quotation_stk_limit`、`ts_quotation_moneyflow`；共 6 张 Tushare 表和 1 张外部行业表 |
| 交易日历导出 | `ts_basic_trade_cal` |
| 指数股票池导出 | `ts_idx_index_cons`、`ts_bak_basic` |
| 指数特征导出 | `ths_idx_index_daily` |
| 分钟数据处理 | 已有分钟 CSV，以及含 `Date, Adj_factor` 的日线 CSV |
| 缺失交易日检查 | 含 `Exchange, Date` 的交易日历 CSV、股票日线 CSV，以及含 `ts_code, trade_date, suspend_type` 的停复牌 CSV |

## 关联与数据口径

- 股票行情及辅助表按 `ts_code, trade_date` 关联，行业表按 `ts_code` 关联。股票列表需包含 `name, market, list_status, list_date`；Tushare 的 `list_status` 需显式请求输出。
- 外部行业数据按 `INDUSTRY_CONS_COLUMN_MAP` 映射到项目字段，当前股票导出使用 `ts_code, l1_name, l2_name`。行业名称还需匹配项目中的枚举编码。
- 日频接口日期为 `YYYYMMDD`，日线 CSV 的 `Date` 为 `YYYY-MM-DD`，分钟 CSV 的 `trade_time` 包含时分秒；比较和合并前需统一格式。
- `daily` 成交量为手、成交额为千元；`moneyflow` 成交量为手、金额为万元；`daily_basic` 股本为万股、市值为万元。分钟 CSV 的单位取决于数据来源，处理脚本不做单位换算。
- `moneyflow` 从 2010 年开始，`bak_basic` 从 2016 年开始，`stk_limit` 从 2007-01-04 开始。准备历史数据时需考虑不同表的覆盖范围，不能假定辅助表覆盖全部日线历史。

字段、单位及历史范围以表格链接的官方文档为准；运行命令和当前限制见 [README](../README.md)。
